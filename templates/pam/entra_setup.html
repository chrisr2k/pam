Setup Guide

Follow these steps to configure Microsoft Entra ID for this PAM application.

1 Create an App Registration

Go to the Azure Portal → Microsoft Entra ID → App registrations → New registration.

NamePAM-App
Supported account typesAccounts in this organizational directory only
Redirect URIWeb → {{ callback_url }}

Click Register. Copy the Application (client) ID and Directory (tenant) ID from the overview page.

2 Create a Client Secret

In your app registration, go to Certificates & secrets → Client secrets → New client secret.

  • Give it a description (e.g. PAM Secret)
  • Set an expiry period (12 months recommended)
  • Click Add
Copy the secret value now — you won't be able to see it again after leaving this page.
3 Configure API Permissions

Go to API permissions → Add a permission → Microsoft Graph.

Delegated permissions (for user sign-in):
  • openid
  • profile
  • email
  • User.Read
Application permissions (for PIM automation):
  • RoleManagement.ReadWrite.Directory

Click Grant admin consent for your organization.

4 Enable PIM (Optional)

To use PIM role activation, go to Entra ID → Identity Governance → Privileged Identity Management → Azure AD roles.

  • Select roles you want to manage
  • Add eligible assignments for users
  • Configure role settings (activation max duration, approval requirements, etc.)
5 Add Entra Roles in PAM

After configuring Entra, add the roles you want to manage:

  1. Go to Django Admin → Roles → Privileged roles
  2. Click Add privileged role
  3. Set Provider to ENTRA
  4. Set External ID to the Entra role definition GUID

Find role GUIDs via: az rest --method GET --uri "https://graph.microsoft.com/v1.0/roleManagement/directory/roleDefinitions"

✓ Test the Configuration

Once you've saved the settings above:

  1. Open an incognito/private browser window
  2. Navigate to /accounts/login/
  3. You should see a "Sign in with Microsoft" button
  4. Click it and authenticate with your corporate credentials
If you see a local username/password form instead, the configuration is incomplete or incorrect.
