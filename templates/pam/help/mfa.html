Multi-Factor Authentication

PAM protects elevation with time-based one-time passwords (TOTP) — the 6-digit codes from an authenticator app. It is not your login password; it proves it's really you at the moment you take a privileged action.

Do I need it?
  • Approvers, admins, and staff: yes — you must enroll before approving or using break-glass. The app will send you to MFA Setup the first time.
  • Anyone listed as an approver of a role is also required to enroll.
  • Everyone else: optional. If enrolled, your own submissions and vault reveals will also ask for a code.
Setting it up (one time, ~1 minute)
  1. Open the user menu (top right) → MFA Setup.
  2. Scan the QR code with Microsoft Authenticator, Google Authenticator, 1Password, or any TOTP app — or type the secret manually.
  3. Enter the 6-digit code from the app and click Activate MFA. Codes with spaces ("123 456") are accepted.
When will I be asked for a code?
  • Submitting a request (if enrolled)
  • Approving a request
  • Revealing a vault secret (if enrolled)
  • Break-glass (always)

Denying or revoking never asks for a code — those are safe actions.

Troubleshooting
  • "Invalid verification code": the code rotates every 30 seconds — use the current one; make sure your phone's clock is set to automatic time.
  • Locked out: 5 wrong codes lock you out for 15 minutes. Signing out and back in resets the lockout.
  • Stale/expired challenge: challenges last 10 minutes and are single-use. Go back to the action and start again.
  • New phone / lost authenticator: you cannot re-enroll without a code from the old device. Ask an administrator to clear your MFA enrollment, then set it up again.
