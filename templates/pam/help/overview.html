Getting Started

PAM (Privileged Access Manager) gives you temporary, just-in-time access to privileged cloud roles and vault secrets — instead of permanent credentials. Access is requested, approved, granted for a limited time, and automatically removed when it expires. Everything you do is audited.

Signing in

You sign in with your organization's Microsoft Entra ID (SSO) account — no separate password. Your first login creates your PAM account automatically.

Key concepts
Role
A bundle of access — an AWS permission set, an Entra ID directory role, or a vault secret checkout. You request a role, not raw permissions.
Request
Your ask for a role, with a justification and a duration. It follows the lifecycle: PENDING → APPROVED → PROVISIONING → PROVISIONED → expired.
Just-in-Time (JIT)
Access exists only while you need it. When the timer runs out (or you revoke it), it is removed from the cloud provider automatically.
Checkout
The vault version of a request: temporary permission to view one secret.
